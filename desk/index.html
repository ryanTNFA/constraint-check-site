Constraint Check (prototype)

Choose an economy

See which of a dozen standard explanations for weak private investment the public data can rule out in a country, which deserve a closer look, and where the data cannot tell. It uses the growth-diagnostics method behind MCC's constraints analyses. It never recommends funding.

Have a program idea? Pick a country, then use “Test a program idea with your AI assistant” on its page: the Desk packs the evidence into one file for the AI you already use.

How to read a country page (10 minutes)
  1. Bottom line. What the public data can rule out, what is worth a closer look, and what is unclear, with the reason. “Probably not” is weaker than “ruled out”.
  2. Test a program idea. Describe it and download one file with the evidence and instructions; your own AI assistant does the assessment. The Desk runs no AI and never says “fund this”.
  3. Open any area. Its evidence, what would change the rating, and what to ask in two days in-country. Analyst detail sits behind “Rule detail”.

How we test it. The plan has three parts: a retrospective against published constraints analyses using only the data available at the time, a pre-registered head-to-head against diagnostics now in progress, and a panel of economists given the same information. None has been run yet, so the tool has no track record; treat every rating as a starting point.
