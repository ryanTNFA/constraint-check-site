# Constraint Check Desk (published build)

**Prototype.** Constraint Check's ratings are uncalibrated and may be wrong; most areas read "unclear" because public data cannot settle them. Use it to decide what to ask, not what to fund.

This repository holds only the built static site, served by GitHub Pages at
https://ryantnfa.github.io/constraint-check-site/. It is generated by `build_site.py` in the Constraint Check
source repository (private for now) and overwritten on each release; do not edit it by hand. Each commit message
names the source commit, rubric, engine and data snapshot it was built from.

The New Foreign Assistance (TNFA), 2026.
