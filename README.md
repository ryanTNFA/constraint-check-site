# The Growth Test (published build)

**Prototype.** The Growth Test's ratings are uncalibrated and may be wrong; most areas read "unclear" because public data cannot settle them. Use it to decide what to ask, not what to fund.

This repository holds only the built static site, served by GitHub Pages at
https://ryantnfa.github.io/growth-test-site/. It is generated by `build_site.py` in the Growth Test
source repository (ryanTNFA/growth-test, private for now) and overwritten on each release; do not edit it by hand. Each commit message
names the source commit, rubric, engine and data snapshot it was built from.

Renamed from Constraint Check on 6 November 2026; the old address, ryantnfa.github.io/constraint-check-site/, redirects here.
